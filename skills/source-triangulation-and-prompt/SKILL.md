# Source Triangulation and PROMPT

Verify whether multiple agreeing sources are truly independent and score source reliability with the PROMPT checklist.

## When to Use

- The user asks whether a website, article, or claim is trustworthy.
- Multiple websites repeat the exact same fact and the user assumes it is confirmed.
- The user needs a structured credibility audit for research citations.

## Procedure

1. Check fact-checking databases such as Full Fact (UK) or Snopes (US) for known public-policy claims.
2. Trace the provenance chain of every agreeing source to test **Independent Triangulation**.
3. Check if multiple articles copy from one original author or press release.
4. If all sources trace back to one origin, flag the **Creeping Fox Terrier Clone** trap.
5. Do not count copied citations as independent confirmation.
6. Evaluate each remaining primary source using the six **PROMPT** criteria:

| Criterion | Audit Question |
| :--- | :--- |
| **Presentation** | Are grammar, spelling, and layout clear and consistent? |
| **Relevance** | Does the source directly answer the specific question? |
| **Objectivity** | Does the author state commercial, political, or personal bias? |
| **Method** | Are survey, journalism, or scientific methods clearly explained? |
| **Provenance** | Does a trusted body (university, gov, peer-reviewed journal) publish it? |
| **Timeliness** | Is the creation or update date visible and valid for the topic? |

7. Assign a score (`Pass`, `Partial`, or `Fail`) to each PROMPT criterion.
8. State a clear reliability verdict grounded in the six scores and triangulation result.

## Gotchas

- High agreement across ten websites proves nothing if nine of them copied the first one.
- A neat layout (`Presentation`) does not guarantee `Objectivity` or `Method`. Always score all six criteria.
