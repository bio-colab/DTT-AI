# Argument Synthesis (Maps to Words)

Transform a completed argument map into clear prose with explicit signposting and a reasoned conclusion.

## When to Use

- The user has an argument map and asks to write an essay, report, email, or appeal.
- The user wants a balanced synthesis that weighs supporting and opposing evidence.
- The user asks for a reasoned conclusion rather than a one-sided opinion.

## Procedure

1. Validate the input argument map first using `argument-mapping-core`.
2. Write the opening paragraph to state the Main Claim clearly.
3. Add one sentence that explains why the Main Claim matters.
4. Write the next section to present all `SUPPORT` claims and their base evidence.
5. Open the supporting section with an explicit signpost such as `Let us examine the evidence in favor of this claim.`
6. Write the following section to present all `OPPOSE` claims and their base evidence.
7. Open the opposing section with a contrast signpost such as `However`, `But`, or `By contrast`.
8. Check every evidence node for scope limits such as sample group, age, geography, or condition.
9. State those scope limits explicitly in the prose so you do not over-generalize findings.
10. Write the final section to weigh supporting claims against opposing claims.
11. Open the conclusion with `In conclusion,` and return directly to the Main Claim.
12. State whether the Main Claim is true, false, or partly true and partly false.
13. Explain the exact conditions under which the claim holds or fails.
14. Append a References section for every cited study or source.

## Gotchas

- Never leave the reader to guess how the evidence connects to the conclusion. State the justification explicitly.
- Do not hide weak evidence. If a study only tested Asian women for night blindness, do not claim it proves general eyesight improvement for everyone.
- If the audience needs journalistic style, weave opposing and supporting claims with `while` contrasts. Keep all evidence grounded.
