# Infographic Perspective Auditor

Transform misleading absolute numbers into relative, contextualized comparisons that reveal hidden patterns and reduce bias.

Absolute figures in isolation often mislead because they lack context.

## When to Use

- The user shares large absolute numbers (budgets, debts, troop counts, emissions) and asks for analysis.
- The user wants to design an infographic or visualization that supports critical thinking.
- The user asks to check if a chart or statistic is biased or out of context.

## Procedure

1. Extract every absolute figure from the source text or dataset.
2. Pair each absolute figure with a relevant normalizing denominator:
   - Normalize national spending or debt by **GDP** or **population**.
   - Normalize military or workforce size by **total population**.
   - Normalize event counts by **rate per capita** or **opportunity exposure**.
   - Compare emissions or costs against **counterfactual baselines** (for example, grounded planes vs volcano output).
3. Recalculate the ranking or comparison using the normalized relative metric.
4. Report both the absolute figure and the relative figure side by side.
5. Apply **Plasticity**: test at least two alternative views or groupings of the same data.
6. Check whether a rotated view or filtered slice reveals hidden structure.
7. Audit the visual framing for ideological or confirmation bias.
8. Include opposing perspectives in comparative diagrams so the visual does not become lopsided.

## Gotchas

- Never compare raw totals between countries of vastly different sizes without normalizing first.
- Keep live data sources separate from visual rendering so updates do not require manual redraws.
