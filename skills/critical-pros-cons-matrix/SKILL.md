# Critical Pros and Cons Matrix

Build balanced pros and cons tables and classify digital tools by how they extend human mental capability.

## When to Use

- The user faces a controversial policy or binary choice and needs an impartial overview.
- The user asks whether a software program qualifies as a digital thinking tool.
- The user wants to evaluate how a digital tool extends human cognitive limits.

## Procedure

1. Define the decision question in neutral, non-leading words.
2. Create a two-column table with headers `Pro` and `Con`.
3. Collect relevant points for both sides without taking an early stance.
4. Count the points and weigh the strength of each point against known evidence.
5. If no clear winner emerges, state that the issue involves a trade-off between competing values.
6. When evaluating a digital tool, classify its core mind-tool functions:
   - **Record keeping**: Makes information persistent over time.
   - **Communication**: Makes information portable across distance.
   - **Calculation**: Automates numerical or logical operations.
7. Score the tool against the five digital levers:
   - **Scale**: Handles huge data volumes beyond human memory.
   - **Reach**: Shares or gathers data globally across vast distances.
   - **Speed**: Processes data orders of magnitude faster than humans.
   - **Creation**: Generates models, simulations, or virtual labs safely.
   - **Plasticity**: Allows fast, low-cost editing, undo, and multi-view reorganization.

## Gotchas

- Never pad one column with weak points to force artificial balance. Keep every point substantive.
- Remember that a pros and cons table is a starting filter. For deep evidence chains, escalate to `argument-mapping-core`.
